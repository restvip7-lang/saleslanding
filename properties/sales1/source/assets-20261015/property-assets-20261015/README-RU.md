# Готовые ассеты недвижимости — 15 октября 2026

## Что передать Claude

Передайте весь ZIP, а не скриншоты его содержимого. Распакуйте в проект. Откройте preview.html: это рабочий пример композиции, CSS и каталог иконок. Он не является полной копией сайта и не отправляет заявки.

PNG — отдельные иллюстрации, подготовленные через imagegen по мотивам макета, с прозрачным фоном. Это не пиксельно точные вырезки исходного макета. SVG — самостоятельно подготовленная согласованная система векторных элементов; она проще больших иллюстраций и предназначена для небольших размеров. Данные объекта НЕ встроены в декоративные иллюстрации. Исключения: compass.svg содержит буквы сторон света; floor-5-of-7.svg показывает конкретный этаж 5 из 7. Для другого объекта этот SVG нужно изменить или сформировать по данным.

## Инструкция для реализации

Используй файлы как готовые ассеты. Не перерисовывай PNG примитивами CSS/SVG и не превращай целые разделы в картинки.

Заголовки, тексты, числа, цены, кнопки, поля формы и согласие остаются настоящими HTML-элементами. Сохрани действующие ссылки, аналитику, обработчик формы и переводы.

Финансирование: desktop-сетка из двух колонок приблизительно 1.15fr/1fr, справа две карточки. Внутри левой карточки для текста и иллюстрации зарезервированы разные области. Не ставь текст поверх подробной части рисунка. На телефоне перестрой в одну колонку.

Для PNG используй object-fit: contain. Не обрезай календарь, щит, лицо или ключ через object-fit: cover. Учитывай прозрачные поля при подборе визуального размера. Для декоративных картинок alt="" и pointer-events:none. Портрету нужен осмысленный alt.

Кнопка баннера: flex-shrink:0 и достаточные padding; на мобильном переносить на отдельную строку. Не ограничивать ширину значением, при котором текст обрезается.

Менеджер: заголовок и описание в обычном потоке, портрет в отдельном контейнере, форма в независимой колонке. Не использовать отрицательные отступы и абсолютное позиционирование, которые заставят фото пересекаться с заголовком или формой. В примере выбран безопасный вариант без наложения текста на человека. Визуальные нюансы можно приближать к reference, но читаемость обязательна.

Характеристики: все цифры выводить HTML; уменьшать шрифт через clamp() в зависимости от карточки; держать «м²» в пределах карточки; подпись «Этаж» обязательна. Не встраивать конкретные данные объекта в общий декоративный фон.

Радар и карту реализовать отдельно средствами сайта. В этом пакете нет точной географической карты или анимированного радара. Не выдавать SVG sea-distance.svg за маршрут или точное направление.

Большие PNG оставлены в исходном качестве. Оптимизацию для веба выполняйте на этапе сборки, сохраняя альфа-канал. Оригиналы не перезаписывать. Не переименовывать PNG в SVG: это не векторизация.

## Проверка

Сравни с reference при одинаковой ширине. Проверь 390, 768, 1440 и 1728 px. Не должно быть переполнения, обрезанных единиц измерения, текста под фотографией или рисунками и сжатых кнопок. Для мобильной версии сначала читаемость, затем сходство с desktop.

Декоративные виллы не являются фотографиями объекта и не подтверждают его внешний вид. Формулировки о кредите, сроке ответа и услугах в preview взяты из пользовательского макета; при применении к другому объекту их нужно подтвердить.
